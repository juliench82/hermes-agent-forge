# Shared Workflows

## Core rule
Choose the smallest workflow that satisfies the current goal.

## High-level flow
1. Product Strategist for raw idea shaping.
2. Architect for technical planning.
3. Builder for one task at a time.
4. Quality Guardian for review.
5. Self Improver for ongoing improvements.

## Coordination rules
- One specialist profile at a time.
- Keep handoffs minimal.
- Do not repeat specialist logic across profiles.
- Keep workflow rules centralized here, not in every skill file.

## Output discipline
Every handoff should include:
- current stage
- next profile
- input package
- expected output
- blockers
