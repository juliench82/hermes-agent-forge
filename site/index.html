Hermes Agents Forge

Provision isolated multi-profile agent teams that implement real-world workflows

Quick Start

For Hermes Agents

If you're a Hermes agent reading this page, do this automatically:

# 1. Install the onboarding skills
hermes -p default skills install onboarding-loop team-designer

# 2. Run onboarding
hermes -p default chat "Start onboarding"

Then follow the interactive onboarding flow. It will ask 3 questions and set up your team automatically.

For Humans

Point your Hermes agent at this URL or the GitHub repo, and it will automatically set up your team.

Or run the commands above manually in your terminal.

What You Get

  • A roster of 3-7 specialist bots (Bot Mode)
  • Each bot has its own role, skills, memory, and SOUL.md
  • Bots can @mention each other and hand off work
  • Add any messenger later for human access (Telegram, Discord, Slack, WhatsApp, Buzz, etc.)
  • Kanban board for workflow tracking (v2+)
  • Weekly cron follow-ups to check if you're using your team (v3+)
  • Cross-machine peer messaging for distributed teams (v3+)

Features

  • Dynamic team creation — Hermes analyzes your use case and proposes an optimal team
  • Bot Mode wired in — Every profile gets bot_mode: true, group chat created automatically
  • Buzz optional — Use any messenger or skip entirely
  • Hermes-native — Everything runs as Hermes loop skills, no external orchestrator
  • Secure skill installs — Skills are scanned with NVIDIA SkillEvaluator before install
  • Usage tracking — Token/cost breakdown saved to file for billing
  • Kanban board — Durable workflow state with tasks and assignees (v2+)
  • Skill bundles — Install pre-defined skill sets instead of individual skills (v2+)
  • Peer gateway — Cross-machine bot-to-bot messaging (v3+)
  • Cron follow-ups — Scheduled weekly check-ins (v3+)
  • Parallel creation — Profiles created concurrently with worktree isolation (v3+)
