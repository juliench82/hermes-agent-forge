What Forge does

Forge is a setup assistant for Hermes — not a hosted service. This website only hands you the installer; everything else happens on your own machine, inside Hermes.

Tell Forge, in plain language, what you want to get done. It designs a small team of specialized Hermes assistants around your goal: what each one is responsible for, which tools it may use, and how they hand work to each other. You review the full team first, adjust anything you don't like, and approve it — only then does Forge set everything up and check that it works.

One coordinator comes built in. Every other assistant is designed around your situation — no presets, no one-size-fits-all templates.

Security & trust

  • Plan before writes. Forge always shows the complete team plan and asks for explicit approval before creating or modifying profiles, files, or configuration.
  • No browser required. Installation uses the Hermes terminal / hermes skills install. Cancel any Chrome remote-debugging prompt.
  • No API keys collected here. This site never asks for credentials, and Forge never embeds secrets in generated files.
  • User-space only. Installation lives under ~/.hermes. No sudo, no privileged shell, no curl | bash requirement.
  • Scoped side effects. Third-party skills and external services are called out individually and approved separately.
