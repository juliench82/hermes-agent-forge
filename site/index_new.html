From intent to deployment.

A disciplined, repeatable path for agent-powered products.

  1. 01

    Define the agent

    Set the role, model, tools, memory, and constraints around a clear task boundary.

    agent:
  name: research-assistant
  model: your-provider-model
  tools: [web_search, file_read]
  2. 02

    Compose the workflow

    Chain specialist agents together, condition transitions, and retain the right execution context.

    workflow:
  - researcher: gather_context
  - analyst: synthesize
  - writer: produce_output
  3. 03

    Operate with confidence

    Deploy, monitor, evaluate, and evolve the system in the same engineering loop as the rest of your product.

    hermes deploy production
hermes monitor --realtime
